## 1. مبادئ التصميم

### 1.1 القيم الجوهرية

| القيمة | الترجمة التصميمية |
|--------|------------------|
| **الثقة** | ألوان محايدة هادئة، مؤشرات الحالة واضحة، لا ألوان صاخبة |
| **الوضوح** | هرمية بصرية صريحة، نص عربي مقروء، حجم خط لا يقل عن 16px |
| **الأمان** | إخفاء البيانات الحساسة بصرياً، تأكيدات قبل الإجراءات الحاسمة |
| **البساطة** | أقل خطوات ممكنة لإنجاز كل مهمة |

### 1.2 توجه RTL
- جميع الصفحات باتجاه `dir="rtl"`.
- هوامش وحشوات تنعكس بين اليمين واليسار.
- الأيقونات الاتجاهية (←→) تُعكس مع RTL.

## 2. نظام التصميم (Design System)

### 2.1 الألوان

```css
/* الألوان الأساسية */
--color-primary:        hsl(210, 70%, 40%);   /* أزرق بترولي */
--color-primary-light:  hsl(210, 70%, 95%);
--color-primary-dark:   hsl(210, 70%, 28%);

/* الحالات */
--color-success:        hsl(142, 60%, 38%);   /* أخضر - مسترجَع */
--color-warning:        hsl(38, 90%, 48%);    /* برتقالي - معلَّق */
--color-danger:         hsl(0, 65%, 50%);     /* أحمر - مرفوض */
--color-neutral:        hsl(220, 15%, 55%);   /* رمادي - مغلق */

/* الخلفيات */
--color-bg:             hsl(220, 20%, 97%);
--color-surface:        hsl(0, 0%, 100%);
--color-border:         hsl(220, 15%, 88%);

/* النص */
--color-text-primary:   hsl(220, 25%, 15%);
--color-text-secondary: hsl(220, 15%, 45%);
--color-text-muted:     hsl(220, 10%, 65%);
```

### 2.2 حالات البلاغات — الألوان

| الحالة | اللون | Badge |
|--------|-------|-------|
| `open` | أزرق (`--color-primary`) | مفتوح |
| `matched` | بنفسجي `hsl(270, 60%, 50%)` | مطابَق |
| `claimed` | برتقالي `--color-warning` | مطالَب |
| `recovered` | أخضر `--color-success` | مُسترجَع |
| `closed` | رمادي `--color-neutral` | مغلق |

### 2.3 الطباعة (Typography)


## 4. حالات التفاعل (Interaction States)

### 4.1 حالات الأزرار

```
Normal:   bg-primary, text-white
Hover:    bg-primary-dark (transition 150ms)
Active:   scale(0.97) + bg-primary-dark
Disabled: opacity-50, cursor-not-allowed
Loading:  spinner + text "جارٍ..."
```

### 4.2 حالات حقول الإدخال

```
Empty:    border-border
Focused:  border-primary + ring-2 (primary/20%)
Valid:    border-success + checkmark icon
Invalid:  border-danger + رسالة خطأ تحت الحقل
```

### 4.3 الإشعارات والتنبيهات

```
Success:  ✓ bg-success/10, border-success, text-success-dark
Warning:  ⚠ bg-warning/10, border-warning, text-warning-dark
Error:    ✕ bg-danger/10,  border-danger,  text-danger-dark
Info:     ℹ bg-primary/10, border-primary, text-primary-dark
```

## 5. الاستجابة (Responsive Breakpoints)

```
Mobile:   < 640px   → عمود واحد، قائمة تنقل سفلية
Tablet:   640-1024px → عمودان في الشبكة
Desktop:  > 1024px  → ثلاثة أعمدة في الشبكة، sidebar جانبي
```

## 6. تدفقات المستخدم الرئيسية (User Flows)

### 6.1 تدفق الإبلاغ عن مفقود

```
الصفحة الرئيسية
    → [إبلاغ عن مفقود]
    → إذا غير مسجَّل: صفحة تسجيل الدخول (OTP)
    → نموذج البلاغ
    → تأكيد النشر
    → "تم نشر بلاغك بنجاح 🎉"
    → لوحة المستخدم / قائمة البلاغات
```

### 6.2 تدفق المطابقة والمطالبة

```
لوحة المستخدم → المطابقات
    → عرض مطابقة مقترحة
    → [قبول والتحقق]
    → نموذج المطالبة (إجابة سؤال التحقق)
    → "جارٍ مراجعة مطالبتك"
    → [إشعار] تأكيد أو رفض المطالبة
    → إذا تأكدت: اختيار نقطة أمانة + موعد
    → تأكيد الاستلام
```

## 7. إرشادات إمكانية الوصول (Accessibility)

- جميع الصور تحتوي على `alt` بالعربية.
- عناصر التركيز (focus) مرئية بوضوح (`outline: 2px solid var(--color-primary)`).
- تباين اللون يلتزم بـ WCAG AA (≥ 4.5:1 للنص العادي).
- الأيقونات تعمل مع قارئات الشاشة عبر `aria-label`.
- النماذج تستخدم `<label>` مرتبطة بكل حقل.
